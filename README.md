# 🧠 Propaganda Detection System

This project is an AI-powered web application developed during a training program with the **City of Scientific Research and Technological Applications (SRTA-City)**. It uses cutting-edge Natural Language Processing (NLP) models to detect propaganda in Arabic text.

## 🚀 Overview

The system supports:
- **Binary Classification**: Detect whether a text is propagandistic or not.
- **Multi-label Classification**: Identify specific propaganda techniques in the text.

Built with a full-stack architecture:
- **Frontend**: React.js
- **Backend**: Flask (Python)
- **Models**: Fine-tuned **AraBERT** and **BERT-GPT4 Augmented** models

## 🛠️ Installation

```bash
# Clone the repo
git clone https://github.com/your-username/propaganda-detection-system.git
cd propaganda-detection-system

# Backend Setup
cd backend
pip install -r requirements.txt
python app.py

# Frontend Setup
cd ../frontend
npm install
npm start
```

> Ensure your models are pre-loaded or linked correctly in the backend to enable inference.
